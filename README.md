# صديق المسلم — المصحف الشريف

تطبيق ويب إسلامي متكامل باللغة العربية (RTL) مصمم باحترافية وفق نمط تطبيقات آيفون وبألوان أحادية نقية (أبيض وأسود)، مع الحفاظ على صفحات المصحف المدني الأصيلة بصيغة SVG.

## المزايا الأساسية

1. **المصحف الشريف (صفحات SVG المدنية)**:
   - عرض صور صفحات المصحف المدني الحقيقية المطبوعة (من صفحة ١ إلى ٦٠٤) بجودة عالية ورسم عثماني أصيل.
   - الدعم التام للتقليب بالسحب باللمس والفأرة (السحب لليسار للصفحة التالية، ولليمين للصفحة السابقة في اتجاه RTL).
   - الانتقال السريع عبر فهرس السور (١١٤ سورة)، الأجزاء (٣٠ جزءاً)، أو الإدخال المباشر لرقم الصفحة.
   - حفظ العلامات المرجعية، تحديد الصفحات كمقروءة للختمة، ومتابعة آخر صفحة تم الوصول إليها تلقائياً.
   - تحكم بحجم عرض صفحات المصحف (تكبير / تصغير العرض).
   - وضع ليلي متطور يغير واجهة التطبيق والأزرار دون إعادة تلوين صفحة المصحف (لتبقى صفحة المصحف بكرتونها الكريمي الأصيل).

2. **القرّاء الخمسة المعتمدون**:
   - التلاوات الحية حصرياً من خمسة قرّاء معتمدين بروابط مباشرة من منصة MP3Quran (بدون أي مفاتيح أو وسطاء):
     1. محمد صديق المنشاوي (القارئ الافتراضي)
     2. محمد أيوب
     3. ياسر الدوسري
     4. أحمد بن حميد بن طالب
     5. فارس عباد
   - ألبوم لكل قارئ يضم سور المصحف كاملاً، إمكانية تشغيل السورة المفردة، تشغيل المصحف كاملاً بترتيب القائمة، والتحميل للاستماع دون اتصال مع زر إلغاء فوري يدعم `AbortController` وعرض نسبة وسورة التقدم الحالية.
   - تشغيل عينة آية فردية بصوت القارئ المختار حالياً من نسخة الآية-بآية على Islamic Network CDN (المنشاوي ومحمد أيوب)، وعند اختيار قارئ ليست له نسخة آية-بآية موثقة تُشغَّل عينة المنشاوي (القارئ الافتراضي) مع عرض اسمه — ودائماً من القرّاء الخمسة فقط.

3. **التفسير والحفظ**:
   - تفسير ابن كثير بالعربية مباشرة من منصة **Quran.com v4** (مع التخزين المؤقت في IndexedDB).
   - إمكانية التبديل إلى تفاسير أخرى معتمدة (التفسير الميسر، القرطبي، الجلالين، البغوي، الوسيط).
   - تعقيم آمن لوسوم HTML وعرض زر «عرض المزيد من التفسير / عرض أقل» للنصوص الطويلة.
   - تلوين تقريبي لأحكام التجويد مع دليل توضيحي مفصل.
   - وضع الحفظ والاختبار الذاتي (إخفاء الآيات مع الكشف التدريجي أو إظهار بداية الآية فقط وتقييم الإجابة صحيح/أعد المحاولة مع حساب نسبة الدقة).

4. **الختمة والورد اليومي**:
   - آية اليوم (متجانسة مع التاريخ الهجري/الميلادي) مع إمكانية مشاركتها كصورة PNG مصممة باحترافية أو عبر خيارات المشاركة الأصلية للمتصفح.
   - متابعة تقدم الختمة (نسبة إنجاز ٦٠٤ صفحة، تحديد الهدف اليومي بصفحات).
   - تذكير الورد اليومي مع طلب إذن الإشعارات الفعلي (`Notification.requestPermission()`) وإشعارات النظام.

5. **العمل دون اتصال (PWA / Caching)**:
   - تخزين مؤقت لصفحات المصحف (SVG)، السور الصوتية، والتفاسير في `Cache API` و`IndexedDB` ليعمل التطبيق بكفاءة كاملة بدون إنترنت بعد التحميل الأول.

## مصادر البيانات الحية

- **صفحات المصحف (SVG)**: منصة الفرقان (`https://alfurqan.online/api/v1/quran-text/page/{1-604}`).
- **الفهرس والبحث**: واجهة AlQuran Cloud (`https://api.alquran.cloud/v1`).
- **التلاوات الصوتية والقرّاء**: منصة MP3Quran v3 (`https://www.mp3quran.net/api/v3/reciters?language=ar`).
- **تفسير ابن كثير**: واجهة Quran.com v4 (`https://api.quran.com/api/v4/tafsirs/14/by_ayah/{surah}:{ayah}`).

## طريقة التشغيل والبناء

1. **تثبيت الحزم**:
   ```bash
   npm install
   ```

2. **تشغيل خادم التطوير المحلي**:
   ```bash
   npm run dev
   ```

3. **بناء النسخة للإنتاج**:
   ```bash
   npm run build
   ```

4. **التحقق من صحة النوع (TypeScript)**:
   ```bash
   npm run lint
   ```
